# Firebat 미니 PC Rocky Linux 설치 가이드

Firebat 미니 PC에 **Windows를 삭제하고 Rocky Linux 10.2 Minimal**을
설치하는 과정을 정리합니다.

> 기준 환경 - Firebat 미니 PC - AMD Ryzen 3 7430U - 내부 SSD 약 512GB -
> Rocky Linux 10.2 x86_64 Minimal - UEFI 부팅 - GUI 없이 서버/개발
> 환경으로 사용

------------------------------------------------------------------------

## 1. 준비물

-   8GB 이상 USB 메모리
-   Rocky Linux ISO
-   Windows PC
-   Rufus
-   유선 키보드
-   HDMI 모니터

Rocky Linux 다운로드:

https://rockylinux.org/download

**x86_64 → Minimal ISO**를 받습니다.

예:

``` text
Rocky-10.2-x86_64-minimal.iso
```

------------------------------------------------------------------------

## 2. 설치 USB 만들기

Windows에서 Rufus를 실행합니다.

설정은 다음과 같이 합니다.

``` text
부트 선택        : Rocky Linux ISO
파티션 구성      : GPT
대상 시스템      : UEFI (non CSM)
파일 시스템      : FAT32
```

`시작`을 누른 뒤 ISO 이미지 모드를 선택하라는 메시지가 나오면:

``` text
ISO Image mode
```

를 선택합니다.

USB에 기존 데이터가 있다면 삭제되므로 중요한 파일이 없는지 확인합니다.

------------------------------------------------------------------------

## 3. USB로 부팅

만든 설치 USB를 Firebat에 연결합니다.

전원을 켜면서 BIOS 또는 Boot Menu 진입 키를 사용합니다.

``` text
DEL : BIOS/Setup
F7  : Boot Menu
```

Boot Menu에서 USB를 선택합니다.

UEFI 환경이라면 USB의 UEFI 부팅 항목을 선택합니다.

------------------------------------------------------------------------

## 4. Rocky Linux 설치 시작

Rocky Linux 설치 화면에서 설치를 진행합니다.

### 언어

원하는 언어를 선택합니다.

### 설치 디스크

Windows를 완전히 삭제하고 Rocky Linux만 사용할 경우:

1.  내부 SSD 선택
2.  기존 Windows 파티션 확인
3.  기존 파티션을 모두 삭제
4.  남은 공간을 Rocky Linux 설치에 사용

> **주의:** 기존 Windows 파티션을 삭제하면 Windows와 해당 파티션의
> 데이터가 삭제됩니다.

내부 SSD가 약 512GB라면 설치 대상 디스크가 약 476GiB로 표시될 수
있습니다. 이는 단위 차이 때문입니다.

------------------------------------------------------------------------

## 5. 사용자 계정 설정

일반 사용자 계정을 하나 생성합니다.

예:

``` text
Full name : Kang
Username  : kang
```

일반적으로 서버 운영은 일반 사용자 + `sudo` 방식으로 사용하는 것이
편합니다.

관리자 권한이 필요하면 해당 사용자를 `wheel` 그룹에 포함시킵니다.

설치 후 확인:

``` bash
id kang
```

`wheel`이 포함되어 있으면 관리자 권한을 사용할 수 있습니다.

예:

``` bash
sudo dnf update
```

------------------------------------------------------------------------

## 6. Root 계정

Root 계정을 사용할 수도 있습니다.

다만 일반적인 작업은 다음과 같이 일반 사용자에서 `sudo`를 사용하는
방식을 권장합니다.

``` bash
sudo <command>
```

Root 셸이 필요하면:

``` bash
sudo -i
```

------------------------------------------------------------------------

## 7. 설치 완료 후 첫 부팅

설치가 끝나고 재부팅하라는 메시지가 나오면 재부팅합니다.

**설치 USB는 제거합니다.**

이후 내부 SSD의 Rocky Linux로 부팅합니다.

로그인:

``` text
localhost login:
```

생성한 사용자 계정으로 로그인합니다.

# 8. 네트워크 확인

유선 LAN을 연결합니다.

네트워크 장치 확인:

``` bash
nmcli device status
```

예:

``` text
DEVICE   TYPE      STATE      CONNECTION
enp2s0   ethernet  connected  enp2s0
lo       loopback  connected  lo
```

IP 확인:

``` bash
ip addr show enp2s0
```

라우팅 확인:

``` bash
ip route
```

------------------------------------------------------------------------

## 9. DHCP로 네트워크 연결

DHCP를 사용하는 경우:

``` bash
sudo nmcli device connect enp2s0
```

연결 프로파일을 DHCP로 설정하려면:

``` bash
sudo nmcli con mod enp2s0 ipv4.method auto
sudo nmcli con up enp2s0
```

연결 확인:

``` bash
ping -c 3 8.8.8.8
```

DNS까지 확인:

``` bash
ping -c 3 google.com
```

> 회사/사내망에서는 외부 IP나 DNS에 대한 ping이 차단될 수 있으므로
> 게이트웨이 또는 사내 서버를 대상으로 테스트할 수 있습니다.

# 10. 고정 IP 설정

고정 IP가 필요한 경우 현재 연결 정보를 먼저 확인합니다.

``` bash
ip addr show enp2s0
ip route
```

예를 들어 다음과 같은 네트워크라고 가정합니다.

``` text
IP       : 128.10.31.61
Prefix   : /16
Gateway  : 128.10.10.1
Interface: enp2s0
```

설정:

``` bash
sudo nmcli con mod enp2s0 \
  ipv4.method manual \
  ipv4.addresses 128.10.31.61/16 \
  ipv4.gateway 128.10.10.1
```

적용:

``` bash
sudo nmcli con down enp2s0
sudo nmcli con up enp2s0
```

확인:

``` bash
ip addr show enp2s0
ip route
```

> **주의:** 사내망의 실제 IP, Prefix, Gateway를 사용해야 합니다. 이미
> 다른 장비에서 사용 중인 IP를 지정하면 IP 충돌이 발생할 수 있습니다.

DNS가 별도로 필요한 경우:

``` bash
sudo nmcli con mod enp2s0 ipv4.dns "DNS주소"
sudo nmcli con up enp2s0
```

# 11. SSH 설정

모니터 없이 원격으로 접속하려면 SSH 서버를 활성화합니다.

``` bash
sudo systemctl enable --now sshd
```

상태 확인:

``` bash
systemctl status sshd
```

미니 PC의 IP 확인:

``` bash
ip addr show enp2s0
```

다른 PC에서:

``` bash
ssh kang@128.10.31.61
```

IP는 실제 설정한 주소로 변경합니다.

# 15. C 프로그램 컴파일

# 16. GDB 사용

``` bash
gdb ./test
```

또는:

``` bash
gdb
```

디버깅 시 유용한 옵션:

``` text
-g       디버깅 정보 생성
-O0      최적화 끄기
-Wall    주요 경고 활성화
-Wextra  추가 경고 활성화
```

개발 중에는 다음과 같이 빌드하면 디버깅하기 편합니다.

``` bash
gcc -g -O0 -Wall -Wextra -o test test.c
```

------------------------------------------------------------------------

# 17. strace 사용

시스템 콜 확인:

``` bash
strace ./test
```

시간을 함께 표시:

``` bash
strace -tt ./test
```

프로세스의 시스템 콜을 더 자세히 확인:

``` bash
strace -f -tt -T ./test
```

-   `-f` : 자식 프로세스/스레드 추적
-   `-tt` : 마이크로초 단위 시간 표시
-   `-T` : 각 시스템 콜 실행 시간 표시

------------------------------------------------------------------------

# 18. Valgrind 사용

메모리 오류 검사:

``` bash
valgrind ./test
```

Memcheck:

``` bash
valgrind --tool=memcheck \
  --leak-check=full \
  --show-leak-kinds=all \
  ./test
```
